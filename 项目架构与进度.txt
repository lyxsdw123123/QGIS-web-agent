================================================================================
QGIS Web Agent MVP —— 项目架构与进度说明
================================================================================

本文件是对「D:\论文\qgis-web-agent-mvp」项目的架构梳理与当前进度记录。
项目目标：复现 https://wing-show.com/projects/qgis-web-agent/ 的核心能力，
即「自然语言 → 服务器端真实地理计算 → 结果上图可下载」。

设计原则：只保留核心链路，不做降级与回退。
  - 大模型不可用时直接报错，不提供规则识别替代方案
  - 地理计算只走真实 QGIS，不做纯 Python 引擎回退
  - QGIS 路径未配置时直接启动失败，不静默退化成裸命令名

二、总体架构
================================================================================

浏览器（Leaflet + OSM 底图 + 聊天 + 图层面板）
        │  fetch（JSON / GeoJSON / multipart / PNG）
        ▼
FastAPI 后端（main.py：路由、.env 加载、静态服务）
        │
        ├── 图层存储 store.py（矢量存 GeoJSON，栅格存文件路径 + 经纬度范围）
        │
        └── 智能体 agent.py
              │  通义千问 Qwen（OpenAI 兼容接口，function calling）
              ▼
        17 个工具
              │
              ├── engine.py   → qgis_process（矢量算法 / 栅格算法 / 栅格化）
              ├── analytics.py → 纯 Python（长度、字段统计、图层检查）
              ├── raster.py   → DEM 获取（AWS Terrain Tiles）+ 栅格转 PNG
              └── geodata.py  → Nominatim（地名/边界）+ Overpass（OSM 道路）
              │
              ▼
        输出 GeoJSON 或 PNG → 返回前端上图、可下载


一次对话的完整流程（SSE 流式）：
  1. 前端 POST /api/chat {text}（fetch + ReadableStream 消费 SSE）
  2. agent 组装系统提示（含图层清单、data 目录文件清单）+ 用户消息
  3. 调 Qwen（qwen-plus）function calling，模型决定调哪个工具
  4. 每步实时推事件：status（进度）→ tool start/end（工具卡片）
     → layer（新图层即时上图）→ final（最终答复）→ error
  5. 前端收到 layer 事件即把新图层叠加到地图（矢量 GeoJSON / 栅格 imageOverlay）

四、17 个工具清单
================================================================================

【图层检查与导出】
 1. inspect_layer        查看图层概况（要素数、几何类型、字段及样例值）
                         → 纯 Python（analytics.inspect_layer）
 2. layer_to_geojson     导出为 GeoJSON，返回下载地址
                         → 本系统图层内部即 GeoJSON，直接给下载地址

【矢量算法（QGIS）】
 3. buffer               缓冲区（米）
                         → native:reprojectlayer → native:buffer → 回转
 4. points_along_lines   沿线按间距生成采样点（米）
                         → native:pointsalonglines（同样做米制往返）
 5. clip                 用面图层裁剪
                         → native:clip
 6. extract_by_attribute 按属性筛选（= != > >= < <=）
                         → native:extractbyattribute
 7. reproject            重投影到指定坐标系
                         → native:reprojectlayer
 8. render_png           出图：栅格直接导出，矢量先栅格化
                         → gdal:rasterize（UNITS=0 像素）→ PNG

【统计（纯 Python）】
 9. total_length         线图层总长度
10. field_stats          字段取值分布与数值统计

【数据加载】
11. load_layer           加载 data 目录下的文件
12. get_osm_roads        按地名取 OSM 道路（Overpass，多镜像重试）
13. get_admin_boundary   按地名取行政区划边界（Nominatim polygon_geojson）

【栅格 / 地形】
14. get_dem              获取 DEM 高程栅格（AWS Terrain Tiles，免 key）
15. slope                坡度        → native:slope
16. aspect               坡向        → native:aspect
17. hillshade            山体阴影    → native:hillshade

说明：坡度/坡向/山体阴影只作用于栅格图层，需先用 get_dem 获取 DEM。
      DEM 与中间栅格放在进程级临时目录（raster.workdir()），退出时清理。


================================================================================
五、API 接口清单
================================================================================

GET    /api/config                          → {engine, model, has_api_key}
GET    /api/layers                          → {layers: [...]}
GET    /api/layers/{id}/data.geojson        → 矢量图层 GeoJSON
GET    /api/layers/{id}/file                → 栅格图层 PNG（浏览器不能显示 GeoTIFF）
GET    /api/layers/{id}/download            → 下载（矢量 GeoJSON / 栅格 PNG）
DELETE /api/layers/{id}                     → 删除图层
POST   /api/layers                          → 上传单个 GeoJSON（multipart）
POST   /api/demo/load                        → 加载示例道路
POST   /api/chat                            → SSE 流（text/event-stream）
                                              事件：status / tool / layer / final / error
GET    /                                    → 前端页面

八、踩坑与修复记录
================================================================================

  1. 下载接口 Content-Disposition 带中文文件名 → latin-1 崩溃
     改用 filename*=UTF-8''...（RFC 5987）
  2. 引擎探测与执行命令名不一致 → 改为显式路径 QGIS_PROCESS_PATH
  3. 【算法 id 猜错】native:reproject 不存在，正确为 native:reprojectlayer
  4. 【key 抄写错误】末尾多抄一个字符导致 401（正确长度 115，错误 116）
  5. 【算法 id 猜错】沿线采样是 native:pointsalonglines，不是 points_along_lines
  6. 【枚举值搞反】gdal:rasterize 的 UNITS：0=Pixels、1=Georeferenced units
  7. 栅格 nodata 为 NaN，转 uint8 报 invalid value in cast → np.nan_to_num
  8. Overpass 单端点 504 → 改为多镜像依次重试
  9. 栅格图层不能让前端按经纬度矢量渲染 → 后端统一转 PNG + 传经纬度范围

教训：QGIS 的算法 id、参数名、枚举值都必须用 `qgis_process list` /
      `qgis_process help <算法>` 查证，不能凭记忆猜。

十、运行方式
================================================================================

  1) 启动服务（直接用 uvicorn 可能因 PATH 找不到，推荐 python -m）：

     cd D:\论文\qgis-web-agent-mvp
     python -m uvicorn backend.main:app --reload --port 8000

     浏览器打开 http://127.0.0.1:8000

  2) 首次生成示例数据（已生成过可跳过）：

     python scripts/make_sample.py

  3) 验证 QGIS 引擎：

     python scripts/check_qgis.py

  4) 可以这样提问（自然语言）：

     - 加载示例道路，看看有哪些字段，筛选主干道并统计长度
     - 获取武汉市江汉区的 DEM，计算坡度和山体阴影
     - 下载武汉市青山区的 OSM 道路，做 200 米缓冲
     - 取湖北省边界，把道路裁剪进去
